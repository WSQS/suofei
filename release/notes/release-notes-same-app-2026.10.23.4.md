## 这一版有什么（相对内容 `2026.10.20.1`）

- **新增 3 首**，分别落在三个朝代组：

  - 刘过《**唐多令·芦叶满汀洲**》—— **新「宋」组的第 1 首**。底本明毛晋汲古阁《宋六十名家词》本《龙洲词》所收《糖多令》的影印 OCR 转录。
  - ⚠ 三首都**未目验任何影印影像**，详情页里照实写着；底本与异文**不据多数票**判定。
- **组数 3 → 4**：汉 → 唐 → **宋** → 近现代。「宋」是这一版**新增的组**（只有 1 首）。
- **合计 31 首 / 4 组**：汉 20（古诗十九首 19 ＋ 垓下歌）＋ 唐 4（望岳、梦李白其一/其二、高轩过）＋ 宋 1（唐多令）＋ 近现代 6（忆秦娥·娄山关 → 卜算子·咏梅，次序未变）。
- **已发布的 28 首逐字段未变**：正文、来源、详情、笔记、标签一个字段都没动（`notes` 仍是全空）；tag `v0.1.4+content-2026.10.20.1` 的产物与资产也**原样保留**。

## ⚠ 升级须知

1. **应用版本没变**（`0.1.4` / `versionCode 5`）：这是**同版本号重打包**，
   装上去只是把**内置内容**换成这一版；已下载的活动内容由 App 自己的更新检查决定（`formatVersion` 兼容时才会采用）。
2. **必须与上一版同一签名才能覆盖安装**。换签名会**安装失败**；先卸载可以装上，但**卸载会丢掉已下载的内容与个人笔记**。
3. **`0.1.3`（`versionCode 4`）及更早的 APK 读不懂 `formatVersion 3`**：要读这一版内容必须装 `versionCode ≥ 5` 的 APK。
4. **旧深链接仍然失效**（0.1.2 起就如此）：作品 ID 是中文路径 ID（如 `古诗十九首-行行重行行`）⇒ 旧 ASCII 链接与书签打不开。
5. **Web 端内容更新＝站点更新**：内容与外壳**成对**切换（同一个站点缓存），所以不存在「旧壳配新内容」。
   本次**应用版本没变、内容修订变了** ⇒ 缓存键从 `pc-resources-0.1.4+<上一版修订>` 换成
   `pc-resources-0.1.4+2026.10.23.4`；浏览器「清除站点数据」会让离线副本丢失，需要联网重新取一次。
6. **`orderInTag` / `orderInSource` 不等于任何外部选本的编次**：唐诗三百首里三首的 1/2/3 是**本库的人工位置**
   （依据只是《唐诗三百首》站内三首相邻的先后核对结论），**不是原刻编号**；古诗十九首的 1–19 依所据来源次序。
