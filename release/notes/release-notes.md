## 这一版有什么

- **标签（本轮的主要变化）**：目录页顶部现在是 **「朝代 ｜ 标签」两个 tab ＋ 右侧「关于」**。
  - 「标签」tab 与「朝代」tab **同构**：都是**组头 ＋ 可点的整行**，初态全部收起，各组展开/收起的**状态独立**，
    题名左沿对齐、作者紧随其后，**不显示序号**。
  - 标签页**不显示任何数量**（也不显示 `orderInTag`）；**只显示有诗的标签**——空标签整组不渲染。
  - **返回逐层**：详情 → 那一首诗 → **进入它时所在的那个 tab**（不是固定回朝代页）；同一会话内两个 tab 的
    展开与滚动**各自保留**。Android 的**系统返回键/返回手势**与页面上的返回按钮走**同一套逻辑**，
    **只有在目录根才退出应用**。
  - 当前两个标签：**古诗十九首**（汉 · 19 首，位置 1–19 依所据来源次序）、
    **唐诗三百首**（唐 · 2 首：杜甫《梦李白二首》其一/其二）。
- **数据格式 `formatVersion: 3`**：每首诗多一个 `tags: [{ id, orderInTag }]`（可为空数组），顶层多一张
  `tags: [{ id, members }]` 表（`id` 即中文显示名，编译期已排好；`members` 已按 `orderInTag` 升序）。
  客户端**一律照产物数组顺序渲染**，标签之间与标签内都不重排（没有 `SortKey` 之类的排序键）。
- **内容**：《古诗十九首》19 首 ＋ 杜甫《梦李白二首》其一/其二 ＋ 毛泽东《七律·和郭沫若同志》
  ⇒ **22 首 / 3 组**（汉 19、唐 2、近现代 1）。正文、来源与上一版**逐字节未变**（本轮只加标签归属）。
- **页面与导航**：仍是四个页面（目录／诗／诗歌详情／关于）；标签 tab **不是第五个页面**，
  它是目录页的第二种分组，有独立深链接 `#/tags`（可直达、可后退出）。
- **详情页**：底本与来源、`### ` 小标题、`- ` 列表等**最小 Markdown 闭集**渲染；没有校记的 6 首**如实说明**，不编内容。
- **笔记入口**按需展开；真实内容里没有笔记时不会出现入口。
- **宽度**：`C = min(V, max(320, 0.88×(V−24)))`；8 档视口实测**无横向溢出**。

## ⚠ 升级须知

1. **内容格式不可逆地升到 `3`**：0.1.3（`versionCode 4`）及更早的客户端**读不懂**这一版内容。
   更新检查会**拒绝**这份内容并**保旧版**——不会损坏、不会半更新、不会出现「旧壳配新内容」。
2. **要读新内容，必须装本页这一版新 APK**（`versionCode 5`）。0.1.3 用户**覆盖安装即可**：
   同一个正式签名（`CN=Suofei`），已下载的内容与个人笔记不丢。
3. **必须与上一版同一签名才能覆盖安装**。换签名会**安装失败**；先卸载可以装上，但**卸载会丢掉已下载的内容与个人笔记**。
4. **旧深链接仍然失效**（0.1.2 起就如此）：作品 ID 已从旧的 ASCII 形式（`gushi-shijiu-shou-NN`）迁移为
   **中文路径 ID**（`古诗九首-<题名>` 形式，如 `古诗十九首-行行重行行`）⇒ 旧链接与书签打不开。
   本轮标签页的深链接是 `#/tags`。
5. **Web 端内容更新＝站点更新**：内容与外壳**成对**切换（Service Worker 同一个站点缓存），
   所以不存在「旧壳配新内容」。浏览器「清除站点数据」会让离线副本丢失，需要联网重新取一次。
   **Web 端本次直接跳到 `@APP_VERSION@`**：停在 `0.1.3` 的站点缓存在新 SW 激活后整套换成新版。
6. **`orderInTag` 不等于任何外部选本的编次**：**唐诗三百首**里《梦李白二首》的 `orderInTag 1/2` 是
   **本库的人工位置**（依据仅是两首相邻先后的核对结论），**不是原刻编号**，也不声称与该选本任何刻本的
   卷次/序号一致。**古诗十九首**的 1–19 依所据来源次序。

## 未验证 / 已知限制（如实说明）

- **物理真机未验证**：本阶段验收基准是**本机模拟器**（用户已定不做物理真机）⇒ 强光下、长时间阅读的
  疲劳感，以及各厂商的图标遮罩效果**都没有在真机上验证过**。
- **无障碍未核**：键盘操作、TalkBack 朗读顺序、颜色对比度**都没有实测**（不是「已通过」，是**没查**）。
- **字体回退与 OLED 观感未验**：缺字时的替代字体、以及 OLED 屏上的深墨底观感**没有实测样本**。
- **组头下的发丝线仍有一处两端差异**：原型组头带 `border-bottom`，Web 端未跟；Android 端两 tab 共用同一个
  `GroupHeaderRow`（含那条既有发丝线）⇒ **该行视觉偏差待用户读回确认**，本轮未据此改任何一端。
- **「关于」与 tab 同字号（0.86rem）只有源码级守卫、无实测像素**：两端源码断言一致，但**没有测量照片**证明
  渲染后确实是同一字号。
- **长笔记只用测试夹具验证过**：真实内容里没有笔记（`notes` 全为空）⇒ 长笔记的排版没有真实样本。
- **更新链路的中间态**（下载中／校验中／待切换）在模拟器上用**本地临时服务**演练过真下载、真校验、
  真激活，以及 sha 不符／截断／格式不兼容时**保旧不切换**；但那次**不是线上站点**、也不是物理真机。
  线上 Pages/Release 的缓存与生效延迟由服务商决定，本流水线**不声称原子性**。
- **未验证**：系统字号放大、WebView 内核表现、窄于 320px 或宽于 1180px 的视口。
- **本页附件之外的构建**：本地演练用的 APK 是 **debug 签名**，**不是**本页这个正式包；请只从本页下载正式 APK。
