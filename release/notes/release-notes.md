- **Android**：下载本页附件的 APK（正式签名证书 `CN=Suofei`）。**装机前请先读下面的「升级须知」。**

## 这一版有什么

- **修复（Android）**：
  - **系统返回键／返回手势**现在按层级返回：详情 → 那一首诗 → 目录；**只有在目录根才退出应用**。
    它与页面上那个「← 返回」按钮**走同一套逻辑**，结果一致。（此前系统返回会**直接退出**应用。）
  - 关于页「**检查更新**」按钮的**上下两条暗缝**已修：背景与边框现在由**同一个表面**绘制
    （不再是外框套在内层底色上）；可点击/触摸范围未变。
- **页面与导航**：目录（顶部只有「关于」这一个入口）／诗／诗歌详情／关于；版本只在关于页。
- **内容**：《古诗十九首》19 首（正文 127 行）＋ 24 条异文校记（分布在 13 首）；
  **另新增 1 首**：毛泽东《七律·和郭沫若同志》（**近现代**组，由用户提供并录入）⇒ 现共 **20 首／2 组**。
- **详情页**：底本与来源、`### ` 小标题、`- ` 列表等**最小 Markdown 闭集**（8 样）渲染；
  没有校记的那 6 首**如实说明**，不编内容。
- **笔记入口**按需展开；真实内容里没有笔记时不会出现入口。
- **宽度**：`C = min(V, max(320, 0.88×(V−24)))`；8 档视口实测**无横向溢出**。

## ⚠ 升级须知（0.1.1 / versionCode 2 及更早的用户请先读）

1. **旧版 APK 打不开这一版的内容**：内容格式已升到 `formatVersion: 2`，旧客户端（`versionCode 2` 及更早）
   与它**不兼容**。更新检查会**拒绝**这份内容，**你原来已经激活的内容保持原样**——不会损坏、不会半更新、
   也不会出现「旧壳配新内容」。
2. **要读新内容，必须装这一版新 APK**（本页附件，`versionCode 3`）。
3. **必须与上一版同一签名才能覆盖安装**：本 APK 用仓库既有的正式签名（`CN=Suofei`）。换签名会**安装失败**；
   先卸载可以装上，但**卸载会丢掉已下载的内容与个人笔记**。
4. **旧深链接会失效**：作品 ID 从旧的 ASCII 形式（`gushi-shijiu-shou-NN`）迁移为**中文路径 ID**
   （`古诗九首-<题名>` 形式，如 `古诗十九首-行行重行行`）⇒ 旧的链接与书签会打不开。
5. **Web 端内容更新＝站点更新**：内容与外壳**成对**切换（Service Worker 同一个站点缓存），
   所以不存在「旧壳配新内容」。浏览器「清除站点数据」会让离线副本丢失，需要联网重新取一次。

## 未验证 / 已知限制（如实说明）

- **物理真机未验证**：本阶段的验收基准是**本机模拟器**（用户已定不做物理真机）⇒ 强光下、长时间阅读的
  疲劳感，以及各厂商的图标遮罩效果**都没有在真机上验证过**。
- 未验证：系统字号放大、字体回退（缺字时的替代字体）、WebView 内核表现、窄于 320px 或宽于 1180px 的视口。
- **长笔记只用测试夹具验证过**：真实内容里没有笔记（`notes` 全为空）⇒ 长笔记的排版没有真实样本。
- **更新链路的其余状态未做端到端演练**：更新「下载中／校验中／待切换」等中间态、以及损坏/不兼容内容进入
  更新流程时的表现，只由设计与单测覆盖（损坏/不兼容一律**保旧版、不切换**）。
- 本地演练用的 APK 是 **debug 签名、`versionCode 2`**，**不是**本页这个正式包；请只从本页下载正式 APK。
