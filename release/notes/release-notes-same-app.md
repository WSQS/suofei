> ⚠ **这是「同 app 版本的内容刷新」**（不是升版发布）：**应用版本与 `versionCode` 都没变**

> - 本页附件是**正式签名**（`CN=Suofei`，与上一版同一张证书）的 `versionCode @VERSION_CODE@` APK，**内置内容已是新的这一版**。
>   ⇒ 装上它**不用联网**也有完整新内容；已装同版本的人**覆盖安装即可**（同签名、不丢本地内容与笔记）。

> - 远端更新清单里的 `minAppVersionCode` 仍是 **@VERSION_CODE@**（内容格式仍是 `formatVersion 3`，

## 这一版有什么（相对内容 `@PREVIOUS_CONTENT_VERSION@`）

> ⚠ **本节由「逐版说明文件」提供，模板里不写具体批次的内容。**
> 发布时若存在 `release/notes/release-notes-same-app-<本次内容版本>.md`，就用它当说明（壳→说明文件替换）；
> 不存在才退到本模板。
>
> 为什么这么定（真实事故，2026-10-23 发现）：模板曾经把**某一批**的具体内容写死，而 CI 只替换版本号那几个占位符
> ⇒ 后续两次同格式发布的正文都把**上一批**的描述又发了一遍，且没有任何门在看「说明与产物是否相符」。
> ⇒ 本模板不再写任何具体诗名/首数；具体内容放在上面那个逐版文件里（`tests/release-notes.test.mjs` 钉住这个约定；
> 事故原文与核对见 `docs/local-stage-delivery.md`）。

具体新增/变化**以本次逐版说明文件为准**（它由发布人从真实产物写，不靠模板自动推导）。
内容清单本身可直接对照站点的 `content/latest.json` 与部署目录里的 `content/<版本>/content.json`。

## ⚠ 升级须知

1. **应用版本没变**（`@APP_VERSION@` / `versionCode @VERSION_CODE@`）：这是**同版本号重打包**，
   装上去只是把**内置内容**换成这一版；已下载的活动内容由 App 自己的更新检查决定（`formatVersion` 兼容时才会采用）。
2. **必须与上一版同一签名才能覆盖安装**。换签名会**安装失败**；先卸载可以装上，但**卸载会丢掉已下载的内容与个人笔记**。
3. **`0.1.3`（`versionCode 4`）及更早的 APK 读不懂 `formatVersion 3`**：要读这一版内容必须装 `versionCode ≥ @VERSION_CODE@` 的 APK。
4. **旧深链接仍然失效**（0.1.2 起就如此）：作品 ID 是中文路径 ID（如 `古诗十九首-行行重行行`）⇒ 旧 ASCII 链接与书签打不开。
5. **Web 端内容更新＝站点更新**：内容与外壳**成对**切换（同一个站点缓存），所以不存在「旧壳配新内容」。
   本次**应用版本没变、内容修订变了** ⇒ 缓存键从 `pc-resources-@APP_VERSION@+<上一版修订>` 换成
   `pc-resources-@APP_VERSION@+@CONTENT_VERSION@`；浏览器「清除站点数据」会让离线副本丢失，需要联网重新取一次。
6. **`orderInTag` / `orderInSource` 不等于任何外部选本的编次**：唐诗三百首里三首的 1/2/3 是**本库的人工位置**
   （依据只是《唐诗三百首》站内三首相邻的先后核对结论），**不是原刻编号**；古诗十九首的 1–19 依所据来源次序。

## 未验证 / 已知限制（如实说明）

- **物理真机未验证**：本阶段验收基准是**本机模拟器**（用户已定不做物理真机）⇒ 强光下、长时间阅读的疲劳感，
  以及各厂商的图标遮罩效果**都没有在真机上验证过**。
- **无障碍未核**：键盘操作、TalkBack 朗读顺序、颜色对比度**都没有实测**（不是「已通过」，是**没查**）。
- **字体回退与 OLED 观感未验**：缺字时的替代字体、以及 OLED 屏上的深墨底观感**没有实测样本**。
- **组头下的发丝线仍有一处两端差异**：Web 端未跟原型组头的 `border-bottom`，Android 端两个 tab 共用含该线的组头行
  ⇒ **该行视觉偏差待用户读回确认**，这一版未据此改任何一端。
- **长笔记只用测试夹具验证过**：真实内容里没有笔记（`notes` 全为空）⇒ 长笔记的排版没有真实样本。
- **更新链路的中间态**（下载中／校验中／待切换）在模拟器上用**本地临时服务**演练过真下载、真校验、真激活，
  以及 sha 不符／截断／格式不兼容时**保旧不切换**；但那次**不是线上站点**、也不是物理真机。
  线上 Pages/Release 的缓存与生效延迟由服务商决定，本流水线**不声称原子性**。
- **未验证**：系统字号放大、WebView 内核表现、窄于 320px 或宽于 1180px 的视口。
- **本页附件之外的构建**：本地演练用的 APK 是 **debug 签名**，**不是**本页这个正式包；请只从本页下载正式 APK。
