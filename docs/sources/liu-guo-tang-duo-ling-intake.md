## 3 汲古阁本读到的原文（逐行照录，含其句读）

词牌题与题下小字：

```
糖多令
安遠樓小集，脩觴歌板之姬黃其姓者乞詞十龍洲道人爲賦此糖。
多令同柳阜之、劉去非、石民瞻、問嘉仲、陳孟參、孟容。時八月五日也。冂譜注重
過武昌。
糖，一作唐。
```

正文：

```
蘆葉滿汀洲，寒沙帶淺流。二十年重過南樓柳
下繫船猶未穩，能幾日又中秋。黃鶴斷磯頭，
故人曾到，不舊江山，渾是新愁。欲買桂花同載
酒，終不似少年遊。
```

（该电子本按影印版面折行，折行处不是句读边界，如「南樓柳／下繫船」是「南樓。柳下繫船」。）

### 3.1 转录可见的字形／OCR 问题（未目验，只作记录）

- 「脩觴」——两处现代转录均作「侑觴」（侑觞＝劝酒），「脩」当是 OCR 之误。
- 「乞詞十」——两处现代转录均作「乞詞于」，「十」当是「于」的 OCR 之误。
- 「問嘉仲」——两处现代转录均作「周嘉仲」。
- 「冂譜注重過武昌」——首字 OCR 不可辨，疑为「詞譜注：重過武昌」（即词谱另题作「重过武昌」），**本库不作断言**。
- 「爲賦此糖。多令」——「糖多令」被版面折行拆开，不是两个词。
- ⚠ **发布前文案口径（2026-10-23，发布前改，未出现在任何已发产物）**：上两条「当是 OCR 之误」是**本仓的推断**，而本库**未目验任何影像** ⇒ 不写进 `detail` 作断言。`detail`（题下注）改成可核表述：「本库题注文字**按明确所取的这份转录整理**：依两处现代排印转录（作「侑觴」「乞詞于」「周嘉仲」）录定，不据单份影印 OCR 定字，也不据此断定原刻用字究竟如何。」推断本身保留在本节。

## 5 题名与题注的身份

- **题名**：本库取「通行词牌＋首句」＝《唐多令·芦叶满汀洲》。底本词牌题作《糖多令》，并有小注「糖，一作唐」；《南楼令》是别名。此写法是本库的题名约定，**不声称是底本原题**。
- **题注**：底本在词题下有一则骈散小注（现代转录本称「小序」「原序」），文字为：
  > 安远楼小集，侑觞歌板之姬黄其姓者，乞词于龙洲道人，为赋此《糖多令》。同柳阜之、刘去非、石民瞻、周嘉仲、陈孟参、孟容。时八月五日也。
- **身份结论**：这则注**见于《龙洲词》一系的词题之下**（汲古阁本排作词牌下小字夹注；两处现代转录本文字与之一致）。本库**不称它为「作者序」**——注中以「龙洲道人」（刘过自号）**第三人称**指称作者，口气是题注／编者附记，不足以断定出于作者自述；它是否刘过自作，**未目验原书影像，不作断言**。
- 因此：这则有据的题注**写进 `detail` 的「### 题下注」一节**；**不加前序字段、不加阅读页新布局**。（旧问题 `q-9a` 的「不加小序」只针对两首毛词，不是全库禁令。）

## 6 系年与背景（未核，不进正文）
