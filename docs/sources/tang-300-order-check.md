## 4. 为什么**不能**把站内次序当作「按原选本编次」

1. **站内丢了结构**：`蘅塘退士《唐诗三百首》` 原书分体编次（五言古诗／五言乐府／七言古诗／七言乐府／五言律诗／七言律诗／五言绝句／七言绝句），而 S11 的书目页**只有一张无标题平表**（§2.1），**没有任何体类或卷次边界**。⇒ 站内次序**不携带**「属哪卷／卷内第几」的信息。
2. **站内次序可疑，不能假定为先刻编次**：目录**首篇**（第 2 条，序之后）是元結《賊退示官吏》，而張九齡《感遇》四首落在**第 32–35 条**（站内顺序：`感遇_(孤鴻海上來)` 32、`感遇_(蘭葉春葳蕤)` 33、`感遇_(幽林歸獨臥)` 34、`感遇_(江南有丹橘)` 35）。这一点只作为**可疑迹象**记录：「首篇不是感遇」是否已足以否定「站内次序＝原刻次序」，本工作线**没有**取证原刻，故**不下判断**——只记一条可用结论：**站内次序不能当作「原选本编次」使用**。
3. **无显式序号**（§3）⇒ 任何「第 N 首」的数字都只能是**本工作线数出来的**，不能冒充站点/原书给出的序号。
