## 3. 自证：怎么跑、看到什么

```bash
D=items/content-format/prototypes/rules-v4

node $D/demo.mjs                    # ① 正常路径：自检 ＋ 自证 ⇒ EXIT 0（PASS 162 / FAIL 0）
node $D/demo.mjs --effects          # ② 「块 → 两端预期」＋「每样语法的两端预期」投影 ⇒ EXIT 0
node $D/demo.mjs --codes            # ③ 错误码表（每个码配哪份夹具）⇒ EXIT 0

node $D/demo.mjs --parse $D/fixtures-invalid/unknown-section.md     # ④ 故意非法 ⇒ EXIT 1 ＋ 诊断原文
node $D/demo.mjs --all-invalid      # ⑤ 12 份非法夹具全部跑一遍 ⇒ EXIT 1
node $D/demo.mjs --dump-diagnostics # ⑥ 能产生的**全部**诊断原文（文档逐字引用它的输出）⇒ EXIT 0
node $D/demo.mjs --verify-docs      # ⑦ 断言文档里逐字引用的诊断原文确实由本演示产生 ⇒ EXIT 0
node $D/demo.mjs --emit $D/samples/real-01-full.md                  # ⑧ 只打 JSON（生成 json/*.json 用）
```

自证覆盖（`demo-output.txt` 是真实输出）：

1. **每份合法样例**：解析无错误；与 `json/*.json` **逐字节一致**（防手抄漂移）。
2. **块 → 两端预期的双向覆盖**：合法样例里出现的块，`expectations.json` 里都有条目；账本里的块也都在样例里真出现过。
3. **最小闭集的双向覆盖**：8 样语法都至少在一份合法样例里被**真正行使**（按行分类探测，不是嘴上说）；样例里出现的语法都在闭集里。
4. **12 份非法夹具的诊断码集与账本逐条相等**（不是「大概会响」）。
5. **结构断言（不靠码名）**：围栏里写了 `## 假标题` ⇒ **只报 1 条**且那段文字**仍留在详情正文里**（证明「围栏内不算分界」）；重复节诊断落在**第二次出现**的那一行；空节 ⇒ 值 `null` 且键仍在；真实《行行重行行》**8 行、单段、首末行逐字相等**；每首 10 键与键序正确；顶层 `dynasties` 是中文值数组。
6. **合成字符串检查（明确标注「不是文件」）**：空白节（`## 笔记` 下只有空格／Tab）、`##详情`（缺空格）、原文里的 `**` 不是粗体、繁体组名 —— 因为**文件里保不住不可见字符**，这几条只在内存里构造并注明。
7. **EXIT 码自证**：另起子进程真跑 1 份合法样例（EXIT 0）＋ 12 份非法夹具（各 EXIT 1 且诊断打在 stderr）＋ 1 个目录外路径（用法错误 EXIT 2）。
8. **依据文件存在性**：`expectations.json` 里每条两端预期引用的 `web/`、`android/`、`tools/`、`docs/` 文件都真实存在（只做 `stat`，**不读内容**）。

**硬边界**：`demo.mjs` **只读本目录**（＋仓库根标记文件）并**本身不写任何文件**；`json/*.json` 是用 `--emit` 的 stdout
在 **shell 里**重定向生成的；`--parse`／`--emit` 只接受本目录内的路径（越界 ⇒ EXIT 2）。
**仓库根不写死层级**：从脚本所在目录向上查找 `prototype/css/theme-tech.css`。
