# ui-hub · 目录页（hub）的表达：组头/诗目/展开记号/入口/对齐/本页宽度行为

- **一句话**：目录页（hub）的表达：组头/诗目/展开记号/入口/对齐/本页宽度行为。
- **父项**：`app-ui`。
- **写入范围**：`items/ui-hub/`（`prototypes/`、`history/`）；材料默认仍放 `items/app-ui/prototypes/`（与本线各轮同处）。

## 当前理解（对话侧维护）

目录负责按时代分组浏览并进入诗歌，不承担搜索或笔记筛选。信息已明确：只留顶部关于入口，不重复应用名；组名＋数量；诗目题名＋作者（次要）。没有搜索、笔记标记、题名预览或正常态版本页脚。

已确认的交互：首次无既有浏览状态全部收起（单组亦如此）、各组独立展开、整个组头可点击；从诗页返回恢复原位置。跨重启记忆、吸顶和宽度边界未定。

下列原型选择仅覆盖相应表达，不是整页采纳；对齐轮选择不自动批准未知的数量关系、行宽、边距和长文本处理。当前材料指向主树实际路径，归档后应修指针；不能仅因有归档README就说文件已搬迁。

## 已选（采纳锚）

- 层级：A 的留白 / 诗目缩进层级；**诗目与组名首字同一竖线（缩进 0）**
- 展开记号：**方括号 `[+]/[−]`**（三角只作对照）
- **记号 ↔ 组名 对齐：悬挂 ＋ 竖直居中**（2026-10-15 用户选；水平几何＝槽 27.52／固定缝 `0.4rem`，竖直＝笔画中心差 1.0px）
- 「关于」入口：**顶部**；作者：**紧随题名、不右对齐**

## 未定 / 开放

- **列宽与间距（⑤）**：未曾表达成选项块 ⇒ 用户反馈若落到这层，负责人再补聚焦材料
- 组名 ↔ 数量 的关系；记号的字号/间距细节
- 本页在 430 以外宽度下的行为 ⇒ 归 `ui-responsive`
