## 这一轮回答什么问题

**诗页「怎么排、谁主谁次」**——两个问题，两页：

- **P1 `q-poem.head.*`：「题名 / 身份信息 / 原文」的主次关系**
  - ① **基线**：题名 → 身份行（作者 · 朝代＋体裁，明显更小更淡）→ 留白 → 原文
  - ② 选项 A：身份行**紧跟题名**（更紧的一组"题头块"）、原文前留白更大
  - ③ 选项 B：题名与身份之间**加一条极淡发丝线**
  - ④ 夹具：有笔记形态（**醒目标注**：测试夹具笔记，不是用户笔记）
- **P2 `q-poem.entries.*`：「返回 / 详情 / 笔记入口」怎样不干扰读诗**
  - ① 基线：返回在上、详情在下（正文上下都不常驻控件）
  - ② 选项 A：返回与详情**同在顶部一行**（无页脚行）
  - ③ 选项 B：两者都移到正文下方（正文上方**零控件**）
  - ④a 有笔记×基线／④b 有笔记×选项B／④c **无笔记对照**（笔记区**整块不存在**：DOM 里没有节点、可见文本里连「笔记」二字都没有）
