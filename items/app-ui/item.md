# 项：页面集合与页面设计

> **当前阶段：讨论中的页面与信息草案，不是已采纳的完整 UI 规格。**
> 用户最新澄清：目前只写了初版元素列表，页面讨论远未定稿；地图与版本安排必须反映这个阶段。此前本项将零散选择整体标为「已采纳」「上线前状态」，该解释被本次澄清替代。

## 当前理解

推进方式：**先讨论有哪些页面，再讨论每页有哪些信息，然后表达内容层级、排布与交互，确认所覆盖的范围后再实施和验收。**

当前页面草案：目录、诗、诗歌详情、关于。

用户已经明确表达的局部取舍保留，不重新问：
- 第一版不做搜索；目录不要「有笔记」标记与题名预览。
- **目录页本轮信息选择**（用户明确答复 `q-1a3dff04`、`q-4b248a11`、`q-52a14e2c`）：全局只保留**关于入口**，不在目录重复显示应用名；组头显示**组名＋诗歌数量**；每首诗显示**题名＋作者**，作者为次要信息。**尚未确认**数量的具体写法、位置、字体，以及题名与作者的对齐/换行方式；这不是整页定稿。
- 阅读页不放底本与来源；另设诗歌详情页承载更多说明。
- **诗页身份信息**（用户明确答复 `q-b7ec35c0`）：题名、作者之外显示**朝代＋体裁**（如「汉 · 五言古诗」），不在阅读页显示更细时代（如「东汉末」）。细时代是否在详情页显示，留到详情页信息讨论，不自动迁入。
- **诗页笔记空状态**（用户明确答复 `q-bed9e64e`）：**没有笔记时隐藏整个笔记区，有笔记时才显示入口**；不显示「暂无笔记」或空的展开按钮。此选择替代此前候选实现中「始终显示笔记入口，展开后显示（无笔记）」的行为；不等于整页设计定稿。
- 关于页两端都有，Android 额外提供更新相关内容。
- **关于页信息清单**（用户明确答复 `q-9f9eca3d`）：两端共用**应用名、应用版本、内容版本、仓库链接**（`https://github.com/WSQS/suofei`）；Android 另有**检查更新动作与状态/结果**。没有因此采纳介绍文案或长篇限制说明；排布和具体文案仍未定。
- 详情可放异文、同书不同本与分段依据；内容如何组织仍在讨论。
- **详情页信息清单**（用户明确答复 `q-480a0665`）：固定仅为**诗题＋返回这首诗的入口＋详情正文**；不固定重复作者、朝代或体裁。详情正文对应源 Markdown 的详情部分；本选择不决定产物字段、切分语法或页面排布。
- 长期上百首、多组；组的可折叠方向、返回目录恢复原位置已表达。
- **目录初始展开规则**（用户明确答复 `q-e571f88e`）：没有既有浏览状态时**全部收起**，先看组名＋数量；只有一个组也如此，接受需多点一次。该选择不覆盖从诗页返回时的状态恢复，也未决定跨重启记忆。**组之间独立展开**（用户明确答复 `q-0736540b`）：可以同时打开多个组，点击只影响该组；接受多组展开后页面可能较长。该轮仅确定行为规则，不确定布局、标记或动画，不授权实施。
- **组头操作范围**（用户明确答复 `q-d28c4e4e`）：**整个组头可点击**，组名、数量与空白属于同一个展开/收起操作；展开标记仅表达状态，不另设独立操作。标记形状、组头样式与诗目的层级关系尚未采纳，下一步通过负责人组织的目录原型讨论。

### 水平原型用户反馈（当前有效，局部采纳）

- **组头内部**：选择「记号悬挂在组名左沿之外」的方向；用户明确指出 `[+]/[−]` 与组名不对齐，**需负责人进一步出原型看对齐**。不把当前候选的偏移、基线、字号或数量位置一并当成批准。
- **诗目左沿**：选水平 body 页**选项B**，**题名与组名首字共用同一左沿（相对缩进为0）**。这取代此前宽泛的「诗目要缩进」助手表述；A的留白层级方向保留，但不能再拿它强制要求正缩进。
- **题名与作者**：选水平 title 页**选项A**，**作者紧随题名，不右对齐成列**。短行示意「行行重行行 佚名」；精确间距、长题名换行及作者跟随的细节仍需在整合原型确认，不外推为所有边界均批准。
