# 项：多浏览视图 UI 原型（可操作 · 候选）

> 父项：[`content-tags`](../content-tags/item.md)。**本期只做原型**：不接正式内容、不改两端产品代码、不发布。

## 必须表达（至少）

1. **原朝代浏览**仍可用（现有目录形态不能被标签视图挤掉）；
2. **标签相关浏览候选**：从某入口进入「某选本」的诗目；**能被看到**「该选本在本库**已收录 N 首**」（**不得**写成「该选本共 N 首/已全收」）；
3. **入口与切换**：从默认视图到标签视图、以及**切回来**（形态**不预先钉**成 tab 还是下拉，也可给多个候选）；
4. **标签下诗目**：与该标签相关的诗、**选本内次序**（与底本次序不同也无妨，原型要说清用的是哪个）；
5. **空标签 / 未收全** 的形态（该选本在本库只有 1 首时怎么显示；标签下没有任何诗时怎么显示）；
6. **进入诗 → 返回原视图与状态**：从标签视图点进诗、再返回，**回到的是标签视图**（不是默认目录），且**滚动/展开等状态**尽量保留；**系统返回**（Android 返回键/手势）也要按同样层级（原型可只表达 Web 侧，但要在「未表达」里说明）；
7. **继承已选**：静默终端配色、已选阅读页（诗页/详情页）、宽度口径 `C=min(V,max(320,0.88*(V-24)))`、顶部信息简洁；
8. **不加**：搜索、编辑器、任何新的诊断/状态栏。

## 交付物落点

- `items/tag-views/prototypes/`：可操作 HTML（**自带临时内嵌数据/明显 fixture**，标明是夹具）+ 关键截图（进入/切换/标签诗目/空或未收全/返回后状态）。
- 回答：**哪些形态已表达、哪些故意未表达**（如系统返回、真机、无障碍）、**继承了哪些已选**、候选之间**代价差异**（tab vs 下拉 vs 独立页）。
- **图必须真看**；完成一份就**立刻送对话侧**（不要等其它候选一起）。
