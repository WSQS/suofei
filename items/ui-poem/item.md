# ui-poem · 诗页（阅读页）的表达：题名/身份/原文的主次、入口位置、水平对齐、本页宽度行为

- **一句话**：诗页（阅读页）的表达：题名/身份/原文的主次、入口位置、水平对齐、本页宽度行为。
- **父项**：`app-ui`。
- **写入范围**：`items/ui-poem/`（`prototypes/`、`history/`）；材料默认仍放 `items/app-ui/prototypes/`（与本线各轮同处）。

## 当前理解（对话侧维护）

阅读页以诗歌原文为主体。固定信息为题名、作者、朝代＋体裁、正文、返回与详情入口；细时代、底本来源、异文不在阅读页显示。无笔记时隐藏整个笔记区，有笔记才显示入口并按需展开（`q-bed9e64e`）；入口位置尚未选。

本轮用户明确选择 P1基线与P2选项A（见下表），但又明确要求进一步看水平对齐与宽度自适应原型。因此垂直主次与顶部入口方向可作为下一轮输入，不能外推为整页或所有宽度已获批准。

采纳材料：父项 `items/app-ui/prototypes/q-poem.md` 与 `q-poem.head.*`／`q-poem.entries.*`。具体内容字段仍在 `content-format` 讨论，本页原型不替它决定。

## 已选（采纳锚，2026-10-15）

**信息层**：题名、作者、**朝代＋体裁**、原文、**返回**、**详情入口**；**不放**细时代、底本/来源、异文；**无笔记 ⇒ 整个笔记区隐藏**（有笔记才显示入口、按需展开）。

**P1 取基线**：

| 元素 | 规格 |
|---|---|
| 题名 | 1.5rem / 500 / 字距 0.1em |
| 身份行 | 作者 · 朝代 · 体裁 ／ 0.78rem ／ `--text-faint` |
| 题名 → 身份 | 0.7rem |
| 身份 → 原文 | 2.1rem |
| 正文 | 17px / 行高 2 / 字距 0.045em |

**P2 取选项 A**：**返回与详情同在顶部一行**（返回左、详情右）；**正文之后没有那个页脚行**。

## 最新采纳：诗页全部居中

用户看补充原型后明确：「诗页全部居中就挺好的」。**采纳 `items/app-ui/prototypes/q-poem-align.html#d4-all`（维度四④a）**：题名、身份行、诗文每一行均居中；不是只把容器居中而文字左齐，也不是仅题头居中。顶部工具栏继承已选返回左/详情右，不参与居中。P1字号/字距/行高/竖向间距继续有效。

该选择收口原型中的主要水平表达方向，不把夹具长题名/长诗句的具体断行算法、所有宽度的行为或有笔记入口位置自动当作已选；长行/窄屏需与宽度原型联合核验。旧的水平备选保留为历史比较，不继续要求用户在它们之间重选。该轮由负责人在后继材料接管后整轮归档、修引用与依赖；此处指针暂指实际当前路径。

## 上轮反馈（已由上述采纳收口）：水平轮需补充全部居中

用户指出现有 `q-poem-align.*` **没有「全部居中」方案，要求重新产出原型**。现轮不能作为已穷尽方向的材料。由负责人组织后继轮，明确题名、身份与诗文行居中的真实效果（不把内容容器居中但文字左齐冒充全部居中）；顶部返回左/详情右的已选范围不默默改掉。具体居中关系与长题名/长行效果由原型表达，用户尚未采纳居中。
